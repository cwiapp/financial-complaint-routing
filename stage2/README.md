# 金融投诉文本自动分类：阶段二数据与实验设计

本目录保存阶段二报告所用的流式数据审计、去重、时间划分、基线比较和合成数据测试。推理特征仅为英文投诉叙述。脚本只写汇总统计，不输出或提交任何真实投诉原文。阶段一的规则被保留为可比较基线；新增的词袋多项式朴素贝叶斯模型由训练集实际拟合。

按六项评分标准修订的报告为 `YangZhao_phase2_report.pdf`，本次提交标签为 `phase-2-submission-v4`；此前的 `phase-2-submission`、`phase-2-submission-v2` 和 `phase-2-submission-v3` 标签保留。团队分工见 [CONTRIBUTIONS.md](CONTRIBUTIONS.md)。报告与两张结果图中的所有文字均为黑色。

## 数据与环境

- Python 3.11 或更新版本。`stage2.py`、`make_charts.py` 与测试仅使用标准库；重新生成 PDF 报告需安装 `reportlab`（见 `requirements.txt`），当前排版脚本还使用 Windows 的微软雅黑字体路径。
- 本机使用的原始文件为仓库外的 `D:\Desktop\金融论文\complaints.csv.zip`，压缩包内应含 `complaints.csv`。这是用户提供的历史快照，SHA-256 必须为 `850d5d220285abecb4d4b94ae4c92a8f318476ce14bd0460c3d6361c79ae9694`。脚本读取前 1,048,575 条记录，与给定 `complaints.xlsx` 可容纳的数据行数对应；脚本会拒绝哈希不符的文件。迁移到其他电脑时，须用 `--data` 指定该 ZIP 的实际路径。数据来源背景及一般下载入口见 [CFPB Consumer Complaint Database](https://www.consumerfinance.gov/data-research/consumer-complaints/)；当前下载未必与本快照相同。
- 压缩包、工作簿与原始叙述不进入 Git 仓库。没有该历史快照时，仍可运行 15 项合成数据测试；完整统计结果保存在 `results/summary.json` 中。由于历史快照的可获取性可能变化，无法保证第三方仅靠公开仓库重建同一原始数据。
- `results/summary.json` 包含完整字段字典、缺失量、六类标签分布、分月叙述量、排除量、模型参数、测试指标与运行环境；`make_charts.py` 从该汇总文件重建两张 SVG 图，`make_data_card.py` 重建 `DATA_CARD.md`。

## 复现命令

在本目录执行：

```powershell
python -m unittest -v test_stage2.py
python stage2.py --data "D:\Desktop\金融论文\complaints.csv.zip" --output results\summary.json
python make_charts.py --summary results\summary.json
python make_data_card.py --summary results\summary.json
```

若要生成 PDF 报告，再执行：

```powershell
python -m pip install -r requirements.txt
python build_report.py
```

`--skip-hash-check` 仅供合成小样本调试，正式结果必须通过输入哈希检查。`--max-rows` 默认为 1,048,575；改变此值会改变研究样本，不能与提交的阶段二结果直接比较。

## 固定实验方案

1. 在已读取的前 1,048,575 条记录中仅选取六个目标产品、非空叙述和有效接收日期。仅叙述参与模型预测；产品标签用于监督，Issue、Sub-issue、公司信息与处理结果等字段不会进入模型。
2. 对叙述做大小写与空白规范化并计算 SHA-256，先按规范化文本全局分组。每组以最早接收日锁定当时可见的产品标签：若最早一日就出现不同产品，整组排除；较晚日期才出现的异标签记录只计入审计，不删除较早的观察。本快照中最早日冲突为 0 组，较晚异标签为 1 组、1 条记录。每组最多保留最早日的一条记录，再按日期分组，使同一文本不跨训练、验证和测试集合。
3. 训练集为 2026-03-31 及以前（3,615 条），2026 年 4 月为验证集（6,112 条），2026 年 5 月为历史复评集（2,742 条）；阶段一已查看的 2026 年 6 月样本排除。划分不随机。五月结果在此前的阶段二版本已被查看，因此不能再称为未查看过的独立测试；本版未按五月结果重新选参，仍只能作回顾性性能描述。
4. 用训练集确定多数类与词袋词表（最小文档频率 2）。词袋模型的平滑系数仅在 4 月验证集上从 0.1、1、5 中选取，不用五月结果选参。删除由 `XXXX` 等遮盖标记构成的词；每份叙述最多使用前 5,000 个英文词元，避免异常长文本支配计算。
5. 三个方法在同一批 5 月样本上比较：训练集多数类、阶段一规则（转人工计为未正确分类，另报告覆盖率与自动处理准确率）、训练后的朴素贝叶斯。报告总体准确率、宏平均 F1、各类召回率与 95% 区间。准确率/覆盖率使用 Wilson 区间；宏 F1 与朴素贝叶斯相对规则的差值使用同一批五月行的 500 次配对自助重采样，种子 42。差值为 0.236，95% 分位数区间为 [0.212, 0.259]；区间只反映这批历史行的抽样波动，不覆盖时序漂移或重复查看的偏差。

## 关键观察与边界

历史快照的 1,048,575 条记录中仅 17,093 条有公开叙述；六类中，征信类 946,029 条记录只有 914 条可用叙述，叙述可得率约 0.097%。这是一份高度选择性的叙述子样本，不能把模型成绩推广到所有投诉。去重后 4 月验证集有 6,112 条，明显多于截至 3 月的训练集 3,615 条；时间分布变化使随机切分尤其不合适。五月规则基线宏平均 F1 为 0.482，朴素贝叶斯为 0.717；两者差值约 0.236，但由于五月已在之前版本查看，不能把此数当作全新前瞻性验证。模型仅做辅助分流，不判断投诉真伪或责任。真实叙述可能包含个人信息，因此不写入日志、测试或公共仓库。

教师对阶段一的逐条评语尚未提供；本阶段按已提供的六项评分标准补齐数据来源与字典、数据质量、去重防泄漏、基线、评估及伦理复现的可检查证据。阶段一预设自动处理正确率须达到 0.85；五月历史复评中词袋朴素贝叶斯全覆盖正确率为 0.742、规则自动正确率为 0.691，均未达此门槛，当前结果不支持无人复核部署。
